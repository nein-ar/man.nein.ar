# man.nein.ar

Source for [man.nein.ar](https://man.nein.ar).

`site/` holds the pages. GitHub Actions publishes `pub/` to GitHub Pages.

The look comes from the [quixotist](https://github.com/nein-ar/quixotist) theme. `site/css/` and `site/img/` hold the files of quixotist's `static/` that the pages load, copied unchanged. The pages themselves are the theme's home and 404 layouts written out by hand.
